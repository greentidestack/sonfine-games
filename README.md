# Sonfine Games

This is a simple gaming website with the essentials. The site includes a search bar that opens URLs, searches Google and the site for games and apps. The site has a games page with over 100 popular web and PC games, apps, and settings such as accent color, alphabetical sorting, tab close prevention, many tab cloaks and more.

I don't own any of the games in the site. If you are the owner of one of the games and would like it removed from the site, please make an issue in this repository.
