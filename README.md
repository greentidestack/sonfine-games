# Sonfine Games

This is a simple gaming website with the essentials. The site includes a custom URL opener and search for Google and the site's games and apps, the site has a games page with over 100 popular web and PC games, apps, and settings such as accent color, alphabetical sorting, tab close prevention, many tab cloaks and more. There are no ads or bloat, though it does not use a real web proxy.  
Some of the games included:   
* Drive mad (Poki version, 200 levels)
* Granny (Steam PC version 1.7 and 1.6)
* Granny 2 (PC versions with and without helicopter upd)
* Ultrakill (free demo)
* Minecraft 1.12
* Escape Road
* Softbody car crash

I don't own any of the games in the site. If you are the owner of one of the games and would like it removed from the site, please make an issue in this repository (with proof of you owning or working for the game).
